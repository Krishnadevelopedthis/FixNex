3. Methodology

{{ assessment.methodology or "OWASP Web Security Testing Guide informed methodology." }}

FixNex orchestrates multiple security tools, normalises their output into a single finding format, correlates duplicate detections, and then manages each finding through verification, evidence collection, risk analysis, remediation and retesting:

  • Reconnaissance — technology fingerprinting and service discovery.
  • Automated scanning — {% if scanners_used %}{{ scanners_used|join(", ") }}{% else %}configured scanner adapters{% endif %}.
  • Normalisation & correlation — results from every tool are mapped to a common schema and deduplicated, so one issue reported by several tools is a single finding.
  • Manual verification — an analyst confirms each finding or records it as a false positive with a documented reason.
  • Evidence collection — artefacts are stored with a SHA-256 hash and chain of custody.
  • Risk analysis — CVSS v3.1 base scoring plus a FixNex contextual risk score that incorporates asset criticality, data sensitivity and exposure.
  • Remediation & retest — findings are assigned with an SLA and closed only after a passing retest.
